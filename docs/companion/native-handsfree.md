# Native desktop conversation

The desktop no longer starts the hands-free web server automatically or offers the browser mode in its character menu. The historical bridge and tests remain in source for reference. Legacy open-handsfree callbacks now toggle native Voice Chat. Open Amma.vbs starts the native application; it does not open a voice website.

Right-click Amma and choose Voice Chat, or use Alt+M where global keyboard hooks are available. One activation starts a continuing microphone session. Alt+I or Interrupt reply stops the current answer without intentionally ending the microphone session. Stop Voice Chat stops capture and playback. Voice interruptions (headphones) enables microphone speech-onset cancellation; three sustained PCM frames above the calibrated threshold trigger it. Speaker-safe mode is the default because this implementation does not provide acoustic echo cancellation. In that mode captured segments overlapping reply work are ignored to avoid transcribing Amma's own speaker output. Use headphones for automatic spoken interruption. Native microphone, playback and echo behavior still require a user hardware trial.

Microphone capture and reply processing use separate workers. A bounded queue keeps the latest completed waiting utterance. Tools observe turn cancellation, stale generated replies are not synthesized after interruption, and playback checks cancellation every 30 ms. In-flight HTTP requests cannot be forcibly interrupted; the next reply can wait for an existing network call to finish. Restart is blocked until the previous reply worker exits. Pause threshold remains 1.5 seconds and the input limit remains 27 seconds. Transcripts appear after STT finishes, not word-by-word while recording. Existing bubble/animation, language rules, saved voice settings, memory and diagnostic journal remain in use.

Validation: 117 Python tests pass, including microphone lifecycle, PCM onset, cancellation, journal, language and tool regressions. No claim of ChatGPT-equivalent echo cancellation, continuous streaming STT or real microphone receipt is made.
