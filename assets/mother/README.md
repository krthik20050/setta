# Mother companion assets

- `artwork/`: source character sheets and approved poses. Application code resolves these through `src/paths.py`.
- `animations/`: exported GIF previews and contact sheets, including earlier iterations and v8.
- `voice/`: teaching audio, shortlist candidates, and selected references. Exact inventory: `docs/voice/mother-voice-status.md` from the project root.

The running source uses the mother's artwork. The unused original cat sprite sheet and row images were removed on 2026-10-20 at the user's request. All mother artwork and voice recordings were retained.
